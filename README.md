# TAILANGHUI® Portfolio — Reference Layout Edition

A responsive visual communication design portfolio template. The homepage composition follows the supplied reference's layout language: oversized cropped title at the top, floating pill navigation, left-side electric-blue geometric forms, a central-right abstract visual composition, a handwritten-style signature, small side index, and bottom scroll cue. It intentionally does not feature an IP character; ZZZ is one project among several.

## Preview
Open `index.html` in a browser.

## Files
- `index.html` — homepage
- `style.css` — layout, responsive styling, animation
- `script.js` — scroll reveals, category filter, particle trail, mobile navigation
- `projects/` — individual project case-study pages

## Customize
Replace the abstract artwork in `.hero-art-stage` with your own designed hero artwork if desired. Update the signature text, about copy, project titles, and contact email in `index.html`.

## GitHub Pages
Upload all files and folders to the root of your repository, then enable GitHub Pages in Settings → Pages.
