# TAILANGHUI® — Motion Portfolio

A responsive visual communication design portfolio inspired by the user-provided reference video. It recreates the broad composition and motion language (dark editorial canvas, oversized cropped typography, blue abstract foreground, layered 3D-inspired object, moving project filmstrip, staggered project cards, cursor particles, scroll reveals and hover responses) without reusing the reference character/artwork.

## Preview
Open `index.html` in a browser. For GitHub Pages, upload the **contents** of this folder to the repository root (not the folder itself), then commit to `main`.

## Files
- `index.html` — homepage
- `style.css` — responsive layout and motion styling
- `script.js` — cursor trail, parallax, scroll effects, reveals and filters
- `projects/` — four project detail-page templates

## Customize
Replace the CSS-generated project artwork with your own portfolio images when ready. Update the contact email in `index.html` from `hello@example.com` to your actual contact address. This is a close stylistic recreation, not a pixel-identical copy of the source website/video; some original 3D/video assets are not included.
