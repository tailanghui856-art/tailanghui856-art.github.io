# Portfolio Template — TAILANGHUI

这是一个参考你提供的 `linshen.com.cn` 截图方向重新设计的作品集模板。

## 视觉结构
- 黑色首页 + 巨型 `Portfolio / TAILANGHUI` 标题
- 红色强调色与强烈的编辑式排版
- 顶部分类导航
- 四个项目入口：ZZZIP / 电商视觉 / 品牌视觉 / AIGC
- 项目详情长页
- 鼠标跟随粒子效果
- 移动端响应式布局

## 替换作品
目前所有大图位置都是 CSS 占位，方便你后面把自己的作品放进去。
建议最终替换：
1. Hero：放你最强的一张 IP / 品牌主视觉
2. ZZZIP：放 ZZZ 主视觉、三视图、表情包
3. E-commerce：放电动牙刷详情页
4. Brand：放 ZZZ 打工人品牌延展
5. AIGC：放最终 AIGC 项目

## GitHub Pages
把 `index.html`、`style.css`、`script.js` 放在 GitHub Pages 仓库根目录即可。

## Authentication / Token
这个仓库本身是静态 GitHub Pages 网站：
- 前端没有登录系统
- 没有 API token
- 没有密码、cookie、JWT 或 OAuth 流程
- 浏览器只读取 HTML/CSS/JS 静态资源

GitHub 的身份验证只发生在“你把代码上传到 GitHub”这一层，不应该把 GitHub Personal Access Token 写进网页源码。
